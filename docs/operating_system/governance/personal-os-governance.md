# Personal OS Governance

Personal OS is the policy layer for one user's Personal Chief of Staff (CoS).

## Scope

- personal prioritization, routing, and context retrieval
- controlled delegation into project-owned execution systems
- privacy-preserving handling of personal context
- generated runtime surfaces for supported personal-agent runtimes

## Authority

Personal OS may recommend, prioritize, summarize, route, and perform authorized
personal-domain actions through the owning domain skill. It does not own project
executor selection, agent profiles, worktrees, Herdr lanes, or project
implementation details. Target Project OS owns those decisions.

## Source of Truth

Policy, behavior, identity, and skills live in repository sources. Generated
runtime files are projections. Private user model and durable memory remain
mutable local state outside Git.
